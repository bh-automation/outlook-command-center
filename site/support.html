Precision Workspace

Persönliches Outlook-Add-in. Es setzt an der geöffneten Nachricht genau eine Status-Kategorie: ACTION, WAITING, PROJECT, DONE oder REFERENCE.

Datenschutz

  • Angezeigt werden nur Absendername, Betreff und Kategorien der geöffneten Nachricht – ausschließlich lokal im Outlook-Fenster.
  • Es werden keine Nachrichteninhalte, Adressen oder Anhänge an einen Server übertragen.
  • Keine Analytics, kein Tracking, keine Cookies, keine Web-Fonts.
  • Einzige externe Datei: Office.js von Microsoft (appsforoffice.microsoft.com).

Berechtigung

ReadWriteItem – nötig, um Kategorien an der geöffneten Nachricht zu setzen oder zu entfernen. Kein Zugriff auf das restliche Postfach.

Entfernen

Outlook → Apps/Add-Ins → Meine Add-Ins → Precision Workspace → Entfernen.
